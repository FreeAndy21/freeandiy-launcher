FreeANDIY Launcher portable mode

While this file sits next to freeandiy-launcher.exe, FreeANDIY Launcher keeps its settings, its
download cache and its record of installed apps in the FreeANDIYLauncherData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move FreeANDIY Launcher with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\FreeANDIY Launcher) instead.
If FreeANDIYLauncherData can't be written (for example on a read-only drive), FreeANDIY Launcher says
so and uses %APPDATA%\FreeANDIY Launcher instead.
